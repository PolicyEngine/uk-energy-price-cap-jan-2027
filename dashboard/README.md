# Dashboard

Next 16, React 19, `@policyengine/ui-kit`, Recharts and bun. It reads one file, `public/data/results.json`, generated by the Python pipeline (`uk-energy-price-cap generate` at the repository root).

```
bun install
bun run dev          # local only
bun run test         # vitest
bun run lint
bun run check-public # public data guard (also runs before every build)
bun run build
```

Tabs: The cap, Household bills (by decile, by group), Support, Household examples, Policies, Methodology. State lives in the address (`?tab=`, `?sub=`, `?scenario=`, `?policies=`). Every page carries the pre-release banner and `noindex` until G4 on the day (docs/RUNBOOK.md). There is no deploy configuration.
